# 表格样式编辑器 · UserForm 1.0

无需安装 JS 加载项。打开 `wps-table-style-macro-1.0.pptm`（压缩包内为 `表格样式编辑器-UserForm-1.0.pptm`），启用 JS 宏，在宏列表或宏编辑器中运行 `OpenTableStyleEditor`。`OpenTableStyleUserForm` 是同一编辑器的入口。

## 使用

1. 点击「打开 PPTX」选择目标文稿，或切换到已保存的 PPTX 后使用「当前文稿」。推荐选择未在 WPS 中打开的目标文件。
2. 选择已有样式，或新建、复制样式。选择需要修改的区域，设置填充、文字、字体和边框。
3. 颜色可用下拉框、HEX 值或色块按钮设置；色块按钮打开独立原生色盘窗体，支持渐变区、色相条、常用色和 HEX/RGB。
4. 选择应用范围后点击保存。保存只修改目标文件；手动重新打开目标文稿查看新样式。

边框线宽默认 1 磅，最低 0.25 磅，最高 20 磅；上下箭头和键盘方向键每次调整 0.25 磅。13 个区域和六方向边框保留，主窗体不提供缩放功能。

## 文件行为

- 模板保留为 PPTM；目标文件必须是本地 PPTX。
- 模板只含一页静态说明。所有交互都在 UserForm 中，没有幻灯片编辑器、幻灯片色盘、页面启动按钮，不需要放映。
- 直接读取已保存的目标文件，不生成临时快照，不调用 `SaveCopyAs`，不生成临时图片，不使用临时目录。
- 已打开的目标文稿必须处于活动状态且已保存正文。宏不会自动调用 WPS 保存正文；未保存时停止操作并提示。
- 保存前检查外部修改并校验生成结果，在目标文件旁保留 `.表格样式备份-时间-ID.pptx` 恢复备份；写入失败会尝试恢复原文件。这是恢复备份，不是用于读取内存文稿的临时快照。
- 保存后不关闭、不重新打开目标文稿。重新打开前避免使用 WPS 原生保存覆盖新样式；关闭询问是否保存时选择不保存，再打开目标文件。

## 平台能力

编辑器与色盘依赖 WPS JS 宏、原生 UserForm 和文件选择能力。文件读写优先使用全局 `FileSystem` 或 `Application.FileSystem`；有该接口时不调用任何系统专用文件 API。旧版 WPS 缺少该接口时，适配层使用 Linux libc / macOS libSystem / Windows kernel32 兜底。UUID 使用 JS Crypto 或纯 JS 生成，无需系统 API。

同一模板适用于三平台，实际能力取决于 WPS 版本。自动测试覆盖打包结构、窗体事件逻辑与三平台系统文件接口；尚未完成三平台 WPS 界面实机验证。需要排查文件接口时，可运行 `DiagnoseTableStyleEditor` 查看实际后端。
